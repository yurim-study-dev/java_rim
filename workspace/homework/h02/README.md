# 🎮 숙제 2 (h02) - 메서드를 활용한 게임 프로젝트

## 📋 프로젝트 개요

**GameFunction.java** - 메서드를 활용한 턴 기반 전투 게임

게임의 각 기능을 메서드로 분리하여 구현했습니다.

---

## 🎯 게임 설정

### 초기값
```
플레이어 HP: 50
적 HP: 10 ~ 99 (랜덤)
필살기 사용 횟수: 1회
```

### 게임 선택지
```
1) 싸운다 - 양쪽 모두 데미지
2) 도망간다 - 소량 데미지, 새 적 출현
3) HP 회복 - 5 회복
4) 필살기 사용 - 강력한 공격 (1회만)
```

---

## 📚 메서드 설명

### 1️⃣ fight(hp, enemyHp) - 전투

**역할:** 플레이어와 적이 서로 공격

**로직:**
```
- 적 데미지: 0 ~ 10 (랜덤)
- 플레이어 데미지: 0 ~ 10 (랜덤)
- 양쪽 모두 데미지를 입음
- 수정된 hp와 enemyHp를 배열로 반환
```

**반환값:**
```
int[] {hp, enemyHp}
```

---

### 2️⃣ runAway(hp) - 도망가기

**역할:** 전투를 피하고 새로운 적을 만남

**로직:**
```
- 도망 중 데미지: 0 ~ 2 (소량)
- hp 감소
- 새로운 적 HP 생성: 10 ~ 99
- 수정된 hp와 새로운 enemyHp 반환
```

**반환값:**
```
int[] {hp, enemyHp (새로운)}
```

---

### 3️⃣ heal(hp) - 체력 회복

**역할:** HP를 5 회복

**로직:**
```
- hp += 5
- 회복 메시지 출력
- 수정된 hp 반환
```

**반환값:**
```
int (수정된 hp)
```

---

### 4️⃣ useUltimateSkill(hp, enemyHp, ultimateSkill) - 필살기

**역할:** 강력한 공격으로 적에게 큰 데미지

**로직:**
```
- 필살기 횟수 확인
- chance = 0 또는 1 (랜덤)
- 데미지 = 적 HP × chance
  (0% 또는 100% 데미지)
- 필살기 횟수 감소
- 수정된 enemyHp와 ultimateSkill 반환
```

**반환값:**
```
int[] {enemyHp, ultimateSkill}
```

---

### 5️⃣ ending(hp, enemyHp) - 게임 종료

**역할:** 게임 결과 판정

**로직:**
```
if (hp <= 0)
  → "당신은 사망했습니다. - The end -"
else if (enemyHp <= 0)
  → "전투에 승리했습니다. - The end -"
```

---

## 🎮 게임 흐름

```
1. 이름 입력
2. while (hp > 0 && enemyHp > 0):
   ├─ 선택지 입력
   ├─ case 1: fight()
   │         └─ 전투 후 자동으로 heal()
   ├─ case 2: runAway()
   │         └─ 도망 후 새 적 생성
   ├─ case 3: heal()
   │         └─ 직접 회복
   └─ case 4: useUltimateSkill()
             └─ 필살기 사용
3. 게임 종료
4. ending() 호출
5. 승패 판정
```

## 💡 핵심 개념

### 배열을 이용한 다중 반환값

**문제:** 메서드에서 여러 개의 값을 반환해야 함

**해결:**
```java
// 두 개의 값을 배열로 반환
return new int[]{hp, enemyHp};

// 호출 시
int[] result = fight(hp, enemyHp);
hp = result[0];           // 첫 번째 값
enemyHp = result[1];      // 두 번째 값
```

### Switch 표현식 (Java 12+)

```java
switch(action) {
    case 1 -> {
        // 코드 실행
        // break 불필요
    }
    case 2 -> { }
}
```

### 메서드 간 값 전달

```
main() → fight(hp, enemyHp)
         ↓
         int[] {hp, enemyHp} 반환
         ↓
main()이 받아서 업데이트
```

## 🔍 특별한 점

### 자동 회복 시스템
```java
case 1 -> {
    int[] result = fight(hp, enemyHp);
    hp = result[0];
    enemyHp = result[1];
    
    hp = heal(hp);  // 전투 후 자동으로 5 회복!
}
```

**특징:** 싸운 후 자동으로 체력이 5 회복됨

### 필살기의 50% 확률
```java
int chance = (int)(Math.random() * 2);  // 0 또는 1
int enemyDamage = enemyHp * chance;     // 0 또는 100%
```

**문제점:** 0%면 대미지 0, 100%면 적을 바로 격퇴
(더 균형있는 데미지 시스템 고려 가능)
