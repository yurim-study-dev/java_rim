- 적 HP: 10 ~ 99 (랜덤)

---

### 게임 흐름

```
1. 캐릭터 이름 입력
2. 적과 전투 선택지:
   - 1) 싸운다
   - 2) 도망간다
   - 3) HP 10 회복
   - 4) 필살기 사용
3. HP <= 0 또는 적 HP <= 0이면 게임 종료
4. 승리/패배 판정
```

## 3. 메서드 분석

### 메서드 1️⃣: fight() - 적과 싸우기

```java
static int[] fight(int hp, int enemyHp) {
    System.out.println("적과 싸웁니다.");
    
    // 적이 준 데미지 (0 ~ 10)
    int enemyDamage = (int)(Math.random() * 11);
    enemyHp -= enemyDamage;
    
    // 플레이어가 입은 데미지 (0 ~ 10)
    int damage = (int)(Math.random() * 11);
    hp -= damage;
    
    // 결과 출력
    System.out.println("적에게 " + enemyDamage + "의 데미지를 주고 " 
                     + damage + "의 데미지를 입었다.");
    System.out.println("나의 남은 체력은 " + hp + "입니다.");
    System.out.println("적의 남은 체력은 " + enemyHp + "입니다.");
    
    // 수정된 hp와 enemyHp를 배열로 반환
    return new int[]{hp, enemyHp};
}
```

**특징:**
- **배열 반환**: 두 개의 값(hp, enemyHp)을 배열로 반환
- **양방향 데미지**: 플레이어와 적 모두 데미지 입음
- **랜덤값**: Math.random() * 11 (0 ~ 10)

**호출 방식:**
```java
int[] result = fight(hp, enemyHp);
hp = result[0];           // 플레이어 HP 업데이트
enemyHp = result[1];      // 적 HP 업데이트
```

### 메서드 2️⃣: runAway() - 도망가기

```java
static int[] runAway(int hp) {
    // 도망 중 입을 데미지 (0 ~ 2)
    int damage = (int)(Math.random() * 3);
    hp -= damage;
    
    // 새로운 적 생성 (HP 10 ~ 99)
    int enemyHp = (int)(Math.random() * 90) + 10;
    
    System.out.println("도망간다. 대신 " + damage + "의 체력이 소비되었다.");
    System.out.println("남은 체력은 " + hp + "입니다.");
    
    // 수정된 hp와 새로운 enemyHp를 반환
    return new int[]{hp, enemyHp};
}
```

**특징:**
- **배열 반환**: hp와 새로운 enemyHp 반환
- **새 적 생성**: 도망 후 새로운 적이 나타남
- **소량 데미지**: 도망 중 0 ~ 2의 데미지

## 4. main 메서드 분석

### 변수 초기화

```java
Scanner s = new Scanner(System.in);
String name = s.next();              // 캐릭터 이름
int hp = 50;                         // 플레이어 HP
int damage = 0;                      // 플레이어 피해량
int ultimateSkill = 1;               // 필살기 사용 횟수
int enemyHp = (int)(Math.random() * 90) + 10;  // 적 HP (10 ~ 99)
int enemyDamage = 0;                 // 적 피해량
```

---

### Switch 표현식 활용

```java
switch(action) {
    case 1 -> {
        // 싸우기
        int[] result = fight(hp, enemyHp);
        hp = result[0];
        enemyHp = result[1];
    }
    case 2 -> {
        // 도망가기
        int[] result = runAway(hp);
        hp = result[0];
        enemyHp = result[1];
    }
    case 3 -> {
        // HP 회복
        hp += 10;
        System.out.println("체력이 10 회복 되었다.");
    }
    case 4 -> {
        // 필살기
        if(ultimateSkill > 0) {
            int chance = (int)(Math.random() * 2);  // 0 또는 1
            enemyDamage = enemyHp * chance;          // 100% 또는 0%
            enemyHp -= enemyDamage;
            ultimateSkill--;
            System.out.println("궁극의 필살기를 사용했다.");
        } else {
            System.out.println("사용할 수 있는 필살기가 없습니다.");
        }
    }
}
```

**특징:**
- **Switch 표현식**: Java 12+ 문법 (->)
- **메서드 호출**: 게임 로직을 메서드로 분리
- **배열 반환값 활용**: fight()와 runAway() 결과 처리

## 5. 핵심 개념 정리

### 배열을 이용한 다중 반환값

```java
// 여러 값을 반환해야 할 때 배열 사용
return new int[]{hp, enemyHp};

// 메서드 호출 시 반환값 처리
int[] result = fight(hp, enemyHp);
hp = result[0];        // 첫 번째 값
enemyHp = result[1];   // 두 번째 값
```

**장점:**
- 여러 개의 값을 한 번에 반환 가능
- 코드가 깔끔하고 읽기 쉬움
- 게임의 상태(hp, enemyHp)를 효율적으로 관리

---

### Switch 표현식의 활용

```java
// 기존 switch 문
switch(action) {
    case 1:
        // 코드
        break;
}

// Switch 표현식 (Java 12+)
switch(action) {
    case 1 -> {
        // 코드
    }
}
```

**Switch 표현식의 장점:**
- 코드가 더 간결함
- break 불필요
- 화살표 문법으로 더 직관적

1. ✅ 메서드를 활용하면 게임 로직을 깔끔하게 분리할 수 있다.
2. ✅ 배열을 반환값으로 사용하면 여러 값을 효율적으로 처리할 수 있다.
3. ✅ Switch 표현식은 Java 12 이후 더 간결한 문법을 제공한다.
4. ✅ 게임의 상태(hp, enemyHp)를 메서드의 매개변수로 전달하고 반환값으로 업데이트한다.
5. ✅ Math.random()으로 다양한 범위의 랜덤값을 생성할 수 있다.
6. ✅ 메서드 호출 시 반환된 배열의 인덱스로 값에 접근한다.
7. ✅ 메서드를 활용하면 코드의 재사용성과 유지보수성이 향상된다.
8. ✅ 게임 루프(while)와 조건문(if, switch)으로 게임의 흐름을 제어한다.
