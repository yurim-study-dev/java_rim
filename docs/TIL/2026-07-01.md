## 함수 - 12 (ex12-01)

함수를 만드는 방법 3가지.

### 함수 선언문

```js
function add(x, y) {
  return x + y;
}
console.log(add(10, 20)); // 30
```

### 함수 표현식

```js
let sum = function(x, y) {
  return x + y;
};
```

### 화살표 함수 (Arrow Function) — 가장 간결한 방식

```js
// 기본
sum = (x, y) => {
  return x + y;
};

// 축약: 실행 코드가 한 줄이면 중괄호 + return 생략
sum = (x, y) => x + y;

// 매개변수가 하나면 괄호도 생략 가능
let add10 = x => x + 10;
```

| 방식 | 특징 |
|------|------|
| 함수 선언문 | 호이스팅 지원 (선언 전에도 호출 가능) |
| 함수 표현식 | 변수에 할당, 선언 후에만 사용 가능 |
| 화살표 함수 | 가장 간결, 현대 JS에서 주로 사용 |

## 이벤트 - 13 (ex13-01 회원가입 폼)

### 이벤트란?

브라우저에서 "뭔가 일어났다"는 신호 — 클릭, 키보드 입력, 폼 전송 등.

### 이벤트 연결 방법 1: 인라인 방식 (HTML 속성)

```html
<!-- 버튼 클릭 시 checkId() 함수 실행 -->
<button type="button" onclick="checkId()">중복 체크</button>

<!-- 폼 전송 시 join(event) 함수 실행, event 객체 직접 전달 -->
<form onsubmit="join(event)">
  <button type="submit">가입</button>
</form>
```

```js
function join(event) {
  // 폼의 기본 동작(서버 전송 + 새로고침) 취소
  event.preventDefault();
  console.log('회원 가입 요청');
}
```

### event.preventDefault() — 핵심!

폼의 submit 기본 동작은 **서버로 데이터 전송 후 페이지 새로고침**.  
`event.preventDefault()` 로 이를 막고 JS로 직접 처리.

### alert / confirm

```js
alert('사용 가능한 아이디입니다.');  // 알림창 (확인 버튼만)

const ok = confirm('성별 없이 진행하시겠습니까?');  // 확인/취소 선택창
if (ok) {
  // 확인 → true
} else {
  // 취소 → false
}
```

## DOM - 14 (ex14-01 게시글 등록, login)

### DOM이란?

브라우저가 HTML 문서를 **객체 트리**로 표현한 것.  
JS로 이 트리를 조작해서 HTML을 동적으로 제어할 수 있음.

```
document
└── html
    ├── head
    └── body
        ├── form
        │   ├── input
        │   └── button
        └── ...
```

### 요소 탐색

```js
// 첫 번째 매칭 요소 반환
document.querySelector('#userId');       // id로 찾기
document.querySelector('.form-group');   // class로 찾기
document.querySelector('input');         // 태그명으로 찾기
document.querySelector('input[name=gender]:checked'); // 선택된 라디오 버튼

// 매칭되는 모든 요소 반환 (유사 배열)
document.querySelectorAll('.list-item');
```

### 폼 요소 값 읽기

```js
// 텍스트 입력 (input, textarea)
const title = document.querySelector('#title');
console.log(title.value); // 입력값 읽기
title.value = '';          // 값 초기화
title.focus();             // 커서 이동

// select
const job = document.querySelector('select[name=job]');
console.log(job.value); // 선택된 option의 value

// checkbox
const agree = document.querySelector('[type=checkbox]');
console.log(agree.checked); // true / false

// radio — 선택된 것만 찾기
const checkedGender = document.querySelector('input[name=gender]:checked');
if (checkedGender) {
  console.log(checkedGender.value); // 'male' 또는 'female'
}
```

### 이벤트 연결 방법 2: addEventListener (실무 권장)

```js
// 인라인 방식 (비권장)
// <button onclick="checkId()">

// addEventListener 방식 (권장) — HTML과 JS를 분리
const writeForm = document.querySelector('#writeForm');

writeForm.addEventListener('submit', function(event) {
  event.preventDefault();
  // 검증 로직
});
```

> **인라인 방식 vs addEventListener 방식**  
> 인라인: HTML에 JS 로직이 섞임 → 유지보수 어려움  
> addEventListener: HTML(구조)과 JS(동작)를 분리 → 실무 표준

## script defer 속성 (login.html)

```html
<!-- defer 없이 head에 script 넣으면 HTML 파싱 전에 JS 실행 → DOM 못 찾음 -->
<script src="login.js"></script>

<!-- defer: HTML 파싱 완료 후 JS 실행 → DOM 준비 보장 -->
<script defer src="/login.js"></script>
```

```js
// login.js — defer 덕분에 아래 코드가 DOM 로딩 후 실행됨
const loginForm = document.querySelector('.login-form');

loginForm.addEventListener('submit', function(event) {
  event.preventDefault();
  console.log('로그인 요청');
});
```

| 위치 / 속성 | 실행 시점 | DOM 접근 |
|------------|----------|----------|
| `<head>` (기본) | HTML 파싱 중 즉시 | ❌ DOM 아직 없음 |
| `<body>` 맨 아래 | HTML 파싱 후 | ✅ |
| `<head defer>` | HTML 파싱 완료 후 | ✅ 권장 방식 |

## 배운점

1. ✅ 화살표 함수 축약 — 코드 한 줄이면 `{}` + `return` 생략, 파라미터 하나면 `()` 도 생략.
2. ✅ `event.preventDefault()` — 폼 submit의 기본 동작(서버 전송+새로고침)을 막고 JS로 처리.
3. ✅ `document.querySelector()` — CSS 선택자 문법 그대로 DOM 요소 탐색.
4. ✅ `input.value`, `select.value`, `checkbox.checked`, `radio:checked` — 폼 요소별 값 읽는 속성이 다름.
5. ✅ `alert()` vs `confirm()` — confirm은 true/false 반환, 분기 처리에 사용.
6. ✅ `addEventListener` 방식이 인라인 방식보다 권장 — HTML과 JS 분리로 유지보수 편함.
7. ✅ `defer` 속성 — head에 script를 놓아도 DOM 완성 후 실행 보장.
8. ✅ 폼 검증 패턴 — 조건 불만족 시 `alert + focus + return` 으로 처리 흐름 제어.

## 오늘 핵심 정리

```
함수 3가지
  function add(x,y){ return x+y; }   // 선언문
  const add = function(x,y){...};     // 표현식
  const add = (x,y) => x+y;          // 화살표 함수 (축약)

이벤트 연결
  onclick="fn()"           // 인라인 방식 (비권장)
  el.addEventListener(이벤트명, 함수)  // JS 방식 (권장)
  event.preventDefault()   // 기본 동작 취소 (submit 자동 전송 막기)
  alert() / confirm()      // 알림 / 확인+취소 창

DOM 탐색
  document.querySelector(선택자)    // 첫 번째 요소 반환
  document.querySelectorAll(선택자) // 전체 요소 반환 (유사 배열)

폼 요소 값
  input/textarea → .value
  select         → .value
  checkbox       → .checked
  radio          → querySelector('input[name=?]:checked').value

script 로딩
  <script defer src="..."> → HTML 파싱 완료 후 실행 (head에 놓는 권장 방식)
```
