## 네트워크 프로그래밍 - ch04

### 기본 개념

```
IP   = 건물 주소  (어느 컴퓨터인지)
Port = 몇 호실    (그 컴퓨터의 어느 프로그램인지)
→ localhost:50000 = 내 컴퓨터의 50000번 프로그램
```

**자주 쓰는 포트:**

| 포트 | 용도 |
|------|------|
| 80 | HTTP (웹) |
| 443 | HTTPS (보안 웹) |
| 3306 | MySQL |
| 8080 | 톰캣 (자바 웹서버) |

### TCP vs UDP

| | TCP | UDP |
|--|-----|-----|
| 비유 | 등기우편 (전달 확인) | 전단지 (그냥 던짐) |
| 신뢰성 | 높음 (유실 시 재전송) | 낮음 |
| 속도 | 느림 | 빠름 |
| 사용처 | 웹, 파일 전송 | 게임, 영상 스트리밍 |

### 소켓(Socket)이란?

두 프로그램 사이의 **연결 통로**. 연결되면 안에 스트림 2개가 생김.

```java
Socket s = new Socket("localhost", 50000); // 서버에 연결

InputStream in   = s.getInputStream();   // 상대방 데이터 받기
OutputStream out = s.getOutputStream();  // 상대방에게 데이터 보내기
```

### Socket vs ServerSocket

```
[ServerSocket]           [Socket]
= 문지기                  = 실제 대화 창구
= 포트 열고 대기           = 연결되면 데이터 주고받기
accept() 호출 → 클라이언트 오면 Socket 반환
```

```java
// 서버
ServerSocket ss = new ServerSocket(50000);
Socket client = ss.accept(); // 클라이언트 올 때까지 대기 (블로킹)

// 클라이언트
Socket s = new Socket("localhost", 50000); // 바로 연결 시도
```

### BufferedReader / PrintWriter — 문자 단위 통신

I/O 챕터에서 배운 스트림 + 버퍼를 소켓에도 똑같이 사용.

```java
// 읽기: 한 줄씩 읽기
BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
String data = in.readLine(); // 줄바꿈 나올 때까지 기다렸다가 한 번에 가져옴

// 쓰기: 한 줄씩 보내기 (autoFlush: true → println 할 때마다 자동 전송)
PrintWriter out = new PrintWriter(new OutputStreamWriter(s.getOutputStream()), true);
out.println("안녕하세요");
```

### 에코 서버 실습 (ch04/echo)

**단계 1 - 단일 클라이언트 (EchoServer)**

클라이언트 1명만 받고, 보낸 메시지 그대로 돌려줌.  
한 명 연결되면 다른 사람은 영원히 대기.

**단계 2 - 다중 클라이언트 (EchoServerMulti + EchoServerTask)**

여러 명 동시 접속 가능. 클라이언트마다 스레드를 하나씩 만들어 처리.

```java
// EchoServerMulti - while로 계속 접속 받음
while(true) {
    Socket s = ss.accept();                   // 클라이언트 대기
    EchoServerTask worker = new EchoServerTask(s); // 담당 일꾼 생성
    new Thread(worker).start();               // 스레드로 독립 실행
}
```

```java
// EchoServerTask - 클라이언트 1명 전담
public void run() {
    try(Socket clientSocket = this.s) {
        BufferedReader in = ...;
        PrintWriter out = ...;
        while((readData = in.readLine()) != null) {
            out.println("서버의 응답: " + readData); // 에코
        }
    }
}
```

> **트러블슈팅**: `Address already in use: bind` 오류 → 같은 포트를 쓰는 다른 서버가 이미 실행 중. 기존 서버 종료 후 재실행.

## 멀티스레드 - ch05

### 프로세스 vs 스레드

```
프로세스 = 실행 중인 프로그램 하나 (카카오톡, 크롬 각각 1개씩)
스레드   = 프로세스 안의 실행 흐름 단위 (카카오톡 안에서 채팅/알림/다운로드 동시 처리)
```

스레드끼리는 **Heap(객체), Method Area(클래스/static)를 공유**, Stack만 각자 독립.

### 싱글 vs 멀티 스레드

**싱글 스레드 (ch05/single)**

```java
odd.run();   // 홀수 다 끝나야
even.run();  // 짝수 시작 → 순서대로 실행
```

출력 결과: 홀수 1,3,5,7,9 → 완전히 끝 → 짝수 2,4,6,8,10

**멀티 스레드 (ch05/multi)**

```java
odd.start();                              // 홀수 스레드 시작
new Thread(even, "짝수 스레드").start();  // 짝수 스레드 시작
// 두 스레드가 동시에 실행 → 출력 순서가 섞임
```

출력 결과: 홀수/짝수가 뒤섞여서 나옴 (OS 스케줄러가 순서 결정)

### start() vs run() — 핵심 차이!

```java
odd.run();    // ❌ 그냥 메서드 호출 → 새 스레드 안 만들어짐 (싱글스레드)
odd.start();  // ✅ 새 스레드 생성 후 run() 실행 → 진짜 멀티스레드
```

### 스레드 생성 3가지 방법

**방법 1 - Thread 클래스 상속**

```java
public class OddNum extends Thread {
    OddNum() { super("홀수 스레드"); } // 스레드 이름 지정

    @Override
    public void run() {
        for(int i = 1; i <= 10; i += 2) {
            System.out.println("홀수: " + i);
        }
    }
}
new OddNum().start();
```

단점: 이미 다른 클래스를 상속받고 있으면 사용 불가 (자바는 단일 상속)

**방법 2 - Runnable 인터페이스 구현 (권장)**

```java
public class EvenNum implements Runnable {
    @Override
    public void run() {
        for(int i = 2; i <= 10; i += 2) {
            System.out.println("짝수: " + i);
        }
    }
}
new Thread(new EvenNum(), "짝수 스레드").start();
```

장점: 다른 클래스 상속과 동시에 사용 가능, 작업(Runnable)과 스레드를 분리

**방법 3 - 익명 클래스 (Anonymous Class)**

클래스 이름 없이 즉석에서 한 번만 사용할 때.

```java
new Thread(new Runnable() {
    @Override
    public void run() {
        for(int i = 3; i <= 10; i += 3) {
            System.out.println("3의 배수: " + i);
        }
    }
}).start();
```

### Thread 주요 메서드

```java
Thread.sleep(1000);   // 1초 동안 일시 정지 (1000ms = 1초)
thread.join();        // 해당 스레드가 끝날 때까지 기다림
Thread.currentThread().getName(); // 현재 스레드 이름 가져오기
```

## 배운 점

1. ✅ `Socket` = 연결 창구, `ServerSocket` = 문지기 — 역할이 다름.
2. ✅ 소켓 통신도 I/O 스트림과 동일 — `getInputStream()` / `getOutputStream()`.
3. ✅ `BufferedReader.readLine()` — 한 줄 단위로 읽기, 네트워크 통신에서 자주 사용.
4. ✅ 단일 스레드 서버의 한계 — 한 명 처리 중엔 다른 클라이언트 대기.
5. ✅ 멀티스레드 서버 — 클라이언트마다 스레드 하나씩 → 동시 처리.
6. ✅ `start()` vs `run()` — 반드시 `start()` 써야 새 스레드 생성됨.
7. ✅ 스레드 생성 3가지 — `extends Thread` / `implements Runnable`(권장) / 익명 클래스.
8. ✅ `Address already in use` 오류 — 같은 포트 쓰는 서버가 이미 실행 중.

## 오늘 핵심 정리

```
네트워크 소켓
  Socket s = new Socket("주소", 포트);       // 클라이언트: 연결
  ServerSocket ss = new ServerSocket(포트);  // 서버: 포트 열기
  Socket client = ss.accept();              // 클라이언트 대기 (블로킹)
  s.getInputStream()  / s.getOutputStream() // 스트림으로 데이터 송수신

문자 단위 통신
  BufferedReader in  → in.readLine()         // 한 줄 읽기
  PrintWriter out    → out.println("내용")   // 한 줄 보내기

멀티스레드
  extends Thread    → run() 오버라이딩 → .start()
  implements Runnable → run() 구현 → new Thread(runnable).start() (권장)
  익명 클래스        → new Thread(new Runnable(){ run(){...} }).start()

  .start() = 새 스레드 생성 후 run() 실행  ← 반드시 이걸 써야 함
  .run()   = 그냥 메서드 호출 (멀티스레드 아님!)
```
