## 변수 - 4 / 리터럴 - 5 (ex05-01)

### 변수 선언 3가지

| 키워드 | 특징 |
|--------|------|
| `var` | 구버전 방식, 함수 스코프 |
| `let` | 블록 스코프, 재할당 가능 |
| `const` | 블록 스코프, 재할당 불가 (상수) |

### 리터럴 — 코드에 직접 쓴 고정값

```js
let num1 = 10;           // 숫자
let num2 = 3.14;

const str1 = 'to';
const str2 = "JavaScript";
const str3 = `Welcome ${str1} ${str2} World!`;  // 템플릿 리터럴 — 변수 삽입 가능

let b1 = true;           // 불리언
let b2 = false;

const namu = { name: '나무', age: 9 };  // 객체 리터럴
const arr = [10, 20, 30];               // 배열 리터럴

let nullVal = null;      // 명시적으로 "값 없음"
let unVal;               // undefined — 선언만 하고 값 미할당

// typeof로 타입 확인
console.log(typeof num1, typeof str1, typeof b1, typeof namu, typeof arr, typeof nullVal, typeof unVal);
// number string boolean object object object undefined
```

> `null`의 `typeof`가 `object`인 건 JS의 역사적 버그 — 실제로는 null 타입.

## 데이터 타입 - 6

### Java(강형) vs JavaScript(약형)

```java
// Java — 타입 고정
String name = "하루";
name = 6; // 에러!
```

```js
// JavaScript — 타입 자유
let name = '하루';
name = 6; // 다른 타입으로 재할당 가능 (동적 타입)
```

### 원시 타입 vs 참조 타입

| 구분 | 종류 | 저장 방식 |
|------|------|----------|
| 원시 타입 | number, string, boolean, null, undefined | 변수에 값 직접 저장 |
| 참조 타입 | object, Array, Function 등 | 값의 메모리 주소(참조)를 저장 |

## 연산자 - 7 (ex07-01)

### 산술 / 대입

```js
let age6 = 2 ** 3;   // 8 — 거듭제곱
let age7 = '나이는 ' + age1 + ' 입니다.';  // + 는 문자열 결합도 됨

let age = 20;
age += 5;  // age = age + 5 = 25
```

### 일치(===) vs 동등(==) — 중요!

```js
100 == '100'   // true  — 타입 다르면 형변환 후 비교
100 === '100'  // false — 타입까지 같아야 true
```

> 실무에서는 예상치 못한 형변환 방지를 위해 `===` 사용 권장.

### 논리 연산자의 JS만의 특징

```js
// OR (||): 앞이 falsy면 뒤 값 반환
console.log(null || 'guest');     // 'guest'
console.log(undefined || 'guest'); // 'guest'
console.log('' || 'guest');       // 'guest'

// AND (&&): 앞이 truthy면 뒤 값 반환, falsy면 앞 값 반환
let userName;
console.log(userName && userName.length); // undefined (userName이 falsy라서 앞 반환)
```

### 옵셔널 체이닝 `?.` (Optional Chaining)

```js
// userName이 null/undefined일 때 .length 접근하면 에러 발생
// → ?. 로 안전하게 접근
console.log(userName?.length); // undefined (에러 없이 처리)
```

### falsy 값 (조건문에서 false로 처리되는 것들)

```js
false, 0, NaN, '', null, undefined  // 이 6가지가 falsy
// 나머지는 전부 truthy
```

### 삼항 연산자

```js
let result = num % 2 === 0 ? '짝수' : '홀수';
```

## 조건문 - 8 (ex08-01)

```js
// if - else if - else
if(operator == '+'){
  result = n1 + n2;
} else if(operator == '-'){
  result = n1 - n2;
} else {
  console.log('잘못된 연산자입니다.');
}

// switch — 값이 일치(===)하는 case 실행, break 없으면 아래로 fall-through
switch(operator){
  case '+': result = n1 + n2; break;
  case '-': result = n1 - n2; break;
  default:  console.log('잘못된 연산자입니다.');
}

// 결과 출력에 템플릿 리터럴 활용
console.log(`${n1} ${operator} ${n2} = ${result}`);
```

## 반복문 - 9 (ex09-01)

```js
// while — 조건이 true인 동안 반복
let sum = 0, i = 1;
while (i <= 10) {
  sum += i;
  i++;
}

// for — 횟수가 정해진 반복
sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}

// break — 반복문 즉시 종료
// continue — 현재 반복 건너뛰고 다음으로
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue; // 짝수 건너뜀
  sum += i;
}
```

## 객체(Object) - 10 (ex10-01, 10-02, 10-03)

### 객체가 왜 필요한가? (ex10-01)

```js
// 객체 없이 — 변수가 사용자 수만큼 폭발적으로 늘어남
const haruName = '하루'; const haruAge = 6; const haruHobby = '잠자기';
const namuName = '나무'; const namuAge = 9; const namuHobby = '먹기';
```

### 객체 리터럴 — 가장 많이 사용 (ex10-03)

```js
const haru = {
  name: '하루',
  age: 6,
  hobby: '잠자기',
};

// 속성 접근 방법 2가지
console.log(haru.name);      // dot 표기법
console.log(haru['name']);   // 대괄호 표기법

// 속성 추가
haru.breed = '이탈리안 그레이하운드';
```

### JSON 변환

```js
// 객체 → JSON 문자열
const haruStr = JSON.stringify(haru);
console.log(typeof haruStr); // string
console.log(haruStr);        // {"name":"하루","age":6,...}

// JSON 문자열 → 객체
const haruObj = JSON.parse(haruStr);
console.log(typeof haruObj); // object
console.log(haruObj.age);    // 6
```

> JSON은 서버와 데이터를 주고받을 때 사용하는 표준 데이터 포맷.

## 배열(Array) - 11 (ex11-01)

```js
// 배열 생성
const arr = [100, 200, 300];

// 요소 추가
arr[3] = 400;          // index로 추가
arr.push(500);         // 맨 뒤에 추가
arr.unshift(50);       // 맨 앞에 추가

// 요소 제거 & 반환
arr.shift();           // 맨 앞 꺼내서 제거
arr.pop();             // 맨 뒤 꺼내서 제거

// 요소 교환 (스왑)
let tmp = arr[5];
arr[5] = arr[6];
arr[6] = tmp;

// 배열 순회
for (let i = 0; i < arr.length; i++) {
  console.log(i, arr[i]);
}

// for...of — 값만 꺼낼 때 (인덱스 불필요 시)
for (let elem of arr) {
  console.log(elem);
}
```

| 메서드 | 동작 |
|--------|------|
| `push(값)` | 맨 뒤에 추가 |
| `pop()` | 맨 뒤에서 꺼내고 제거 |
| `unshift(값)` | 맨 앞에 추가 |
| `shift()` | 맨 앞에서 꺼내고 제거 |
| `arr.length` | 배열 요소 수 |

## 배운점

1. ✅ JS는 약형 언어 — 타입을 선언 안 해도 되고, 나중에 다른 타입으로 바꿀 수도 있음.
2. ✅ `===`(일치) vs `==`(동등) — 실무에서는 형변환 방지를 위해 `===` 권장.
3. ✅ `null`의 typeof는 `object` — JS의 역사적 버그, 실제 null 타입과 다름.
4. ✅ OR(`||`), AND(`&&`)는 Java와 다르게 값 자체를 반환 — falsy/truthy 기반 동작.
5. ✅ 옵셔널 체이닝 `?.` — null/undefined일 때 에러 없이 안전하게 속성 접근.
6. ✅ 객체 리터럴 `{ key: value }` 방식이 가장 많이 쓰임.
7. ✅ `JSON.stringify()` / `JSON.parse()` — 객체↔문자열 변환, 서버 통신에서 필수.
8. ✅ 배열 앞/뒤 조작: push/pop(뒤), unshift/shift(앞) — 4가지 메서드 세트로 기억.

## 오늘 핵심 정리

```
변수 선언
  var   → 구버전, 함수 스코프
  let   → 블록 스코프, 재할당 가능
  const → 블록 스코프, 재할당 불가 (주로 const 사용)

데이터 타입
  원시: number, string, boolean, null, undefined
  참조: object(객체), Array(배열), Function(함수)
  약형 언어 → 타입 선언 없음, 동적으로 결정

연산자 핵심
  === : 타입+값 모두 비교 (권장)
  ==  : 형변환 후 비교 (지양)
  ||  : 앞이 falsy → 뒤 값 반환
  &&  : 앞이 falsy → 앞 값 반환
  ?.  : 옵셔널 체이닝 (null/undefined 안전 접근)
  falsy: false, 0, NaN, '', null, undefined

객체
  { key: value }      → 객체 리터럴 (가장 많이 사용)
  obj.key / obj['key'] → 속성 접근
  JSON.stringify(obj)  → 객체를 JSON 문자열로
  JSON.parse(str)      → JSON 문자열을 객체로

배열
  push/pop    → 뒤에 추가/제거
  unshift/shift → 앞에 추가/제거
  arr.length  → 요소 수
  for / for...of → 순회
```
