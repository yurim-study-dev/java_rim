## 람다식 마무리 - ch06/lambda

### 표준 함수형 인터페이스 4종 실습

```java
// Predicate — 조건 판별 (boolean 반환)
Predicate<Integer> checkLimit = num -> num <= 100;
checkLimit.test(120); // false
checkLimit.test(90);  // true

// Consumer — 소비 (반환 없음), 메서드 참조로 줄이기
Consumer<String> writeLog = System.out::println;
writeLog.accept("사용자 로그인");

// Function — 변환 (T → R), 메서드 참조로 줄이기
Function<String, Integer> convert = Integer::parseInt;
convert.apply("100"); // 100

// Supplier — 생성 (입력 없음), 메서드 참조로 줄이기
Supplier<Double> randomVal = Math::random;
randomVal.get(); // 0.0 ~ 0.999...
```

### 실습 문제 풀이

```java
// 주사위: n을 받아서 1~n 사이 랜덤 정수 반환
Function<Integer, Integer> dice = (n) -> (int)(Math.random() * n) + 1;
// Math.random() → 0.0~0.999 → *n → 0~n-1 → +1 → 1~n

// 글자수: String 받아서 길이 반환 (메서드 참조)
Function<String, Integer> strLength = String::length;
strLength.apply("hello"); // 5
```

### 메서드 참조 (`::`) 4가지 형태

```java
Integer::parseInt       // 정적 메서드 참조
String::length          // 인스턴스 메서드 참조 (임의 객체)
System.out::println     // 인스턴스 메서드 참조 (특정 객체)
ArrayList::new          // 생성자 참조
```

## 어노테이션 + 리플렉션 - ch06/annotation

### 커스텀 어노테이션 만들기

```java
@Target(ElementType.METHOD)       // 메서드에만 붙일 수 있음
@Retention(RetentionPolicy.RUNTIME) // 실행 중에도 정보 유지
public @interface MeasureTime {
    String taskName() default ""; // 속성 (기본값 있으면 선택사항)
}
```

### 어노테이션 사용

```java
public class Work {
    @MeasureTime(taskName = "ArrayList 사용") // 속성값 지정
    public void task1() {
        List<String> list = new ArrayList<>();
        for (int i = 0; i < 10000; i++) { list.add("데이터-" + i); }
    }

    @MeasureTime  // 속성 생략 → default 값 "" 사용
    public void task2() {
        List<String> list = new Vector<>();
        for (int i = 0; i < 10000; i++) { list.add("데이터-" + i); }
    }
}
```

### 리플렉션으로 어노테이션 처리 (TimeProcessor)

어노테이션은 정보만 붙이는 것 — 실제로 동작하게 만들려면 **처리기(Processor)** 가 필요.

```java
public class TimeProcessor {
    public void process(Object target) {
        Method[] methods = target.getClass().getDeclaredMethods(); // 모든 메서드 조회

        for (Method method : methods) {
            if (method.isAnnotationPresent(MeasureTime.class)) { // 어노테이션 있는지 확인
                MeasureTime ann = method.getAnnotation(MeasureTime.class);
                String taskName = ann.taskName().isEmpty() ? method.getName() : ann.taskName();

                long start = System.currentTimeMillis();
                method.invoke(target); // 리플렉션으로 메서드 실행
                long end = System.currentTimeMillis();

                System.out.println(taskName + " 소요 시간: " + (end - start) + "ms");
            }
        }
    }
}
```

> **리플렉션(Reflection)** = 실행 중에 클래스/메서드 정보를 동적으로 조회하고 실행하는 기술  
> Spring의 `@Transactional`, `@Controller` 등이 이 원리로 동작함!

| 라이브러리 | 역할 |

| `junit-jupiter-api:6.1.1` | 테스트 어노테이션/Assertions 제공 |

## JUnit 단위 테스트 - test/ch07

### JUnit 5 주요 어노테이션

| 어노테이션 | 실행 시점 | 용도 |
|-----------|---------|------|
| `@Test` | 각 테스트마다 | 테스트 메서드 지정 |
| `@BeforeEach` | 각 테스트 직전마다 | 매번 객체 새로 생성 |
| `@BeforeAll` | 전체 테스트 시작 전 1번 | 공유 객체 1번만 생성 (static) |
| `@DisplayName` | - | 테스트 이름 한글로 표시 |
| `@Disabled` | - | 해당 테스트 임시 제외 |

### 실습 코드 (CalculatorJUnitTest.java)

```java
package ch07;

public class CalculatorJUnitTest {
    private static Calculator calc;

    @BeforeAll // 전체 테스트 중 딱 1번만 실행
    static void setUp() {
        calc = new Calculator();
    }

    @Test
    @DisplayName("두 정수의 덧셈 검증 2, 3")
    void add() {
        int result = calc.add(2, 3);
        assertEquals(5, result, "덧셈의 결과는 5여야 함");
    }

    @Test
    @DisplayName("두 정수의 덧셈 검증 3, 4") // 삼각측량법 — 케이스 추가
    void add_3_4() {
        int result = calc.add(3, 4);
        assertEquals(7, result, "덧셈의 결과는 7이여야 함");
    }

    @Test
    @Disabled // 임시 비활성화
    void divide() {
        assertEquals(1.67, calc.divide(10, 6));
    }

    @Test
    @DisplayName("0으로 나누기 테스트")
    void divide_byZero() {
        assertThrows(ArithmeticException.class, () -> {
            calc.divide(10, 0); // 예외 발생해야 테스트 성공
        });
    }
}
```

### 주요 Assertions 메서드

```java
assertEquals(5, result)         // 예상값 == 실제값
assertThrows(예외.class, 람다)   // 람다 실행 시 해당 예외 발생해야 성공
assertNotNull(object)           // null이 아님
assertTrue(조건)                // 조건이 true
```

### TDD 3단계 사이클

```
RED    → 실패하는 테스트 먼저 작성 (클래스/메서드 아직 없음)
GREEN  → 테스트를 통과하는 최소한의 코드 작성 (하드코딩도 OK)
REFACTOR → 중복 제거, 코드 정리 (테스트가 안전망 역할)
```

## 간이 웹서버 - ch04/webserver

### 전체 구조

```
브라우저 → GET /Hello.html HTTP/1.1 →  WebServerMulti (포트 8080)
                                            ↓ 스레드 생성
                                        WebServerTask
                                            ↓ 파일 읽기
                                        resources/Hello.html
                                            ↓ HTTP 응답
브라우저 ← HTML 내용 ←──────────────────
```

### HTTP 요청 헤더 파싱

```java
// "GET /Hello.html HTTP/1.1" 첫 줄 파싱
String requestLine = in.readLine();
String[] parts = requestLine.split(" ");
String url = parts[1]; // "/Hello.html"

// 나머지 헤더 줄 읽기 (빈 줄 = 헤더 끝)
while ((line = in.readLine()) != null) {
    if (line.isEmpty()) break;
    System.out.println(line);
}
```

### HTTP 응답 전송

```java
String header = "HTTP/1.1 200 OK\r\n"
              + "Content-Type: text/html; charset=UTF-8\r\n";

String body = loadFile(url.substring(1)); // "/Hello.html" → "Hello.html"

out.println(header);
out.println(body); // HTML 파일 내용 전송
```

> **favicon.ico 요청** — 브라우저가 탭 아이콘용으로 자동 전송. 내가 요청한 게 아니라 브라우저가 알아서 보내는 것이라 정상.

## 배운 점

1. ✅ 표준 함수형 인터페이스 4종 — `Predicate`(판별) / `Consumer`(소비) / `Function`(변환) / `Supplier`(생성).
2. ✅ 메서드 참조 `::` — 람다를 더 짧게 줄이는 문법.
3. ✅ 커스텀 어노테이션 — `@interface`로 선언, 속성에 `default` 지정 가능.
4. ✅ 리플렉션 — 실행 중 메서드 정보 조회 (`getDeclaredMethods`) 및 동적 실행 (`method.invoke`).
5. ✅ Spring의 `@Transactional` 같은 것들이 어노테이션 + 리플렉션 원리로 동작함.
6. ✅ `@BeforeAll` vs `@BeforeEach` — 전체 1번 vs 테스트마다 1번.
7. ✅ `assertThrows` — 예외 발생을 테스트하는 방법.
8. ✅ TDD = 테스트 먼저, 코드 나중 — Red → Green → Refactor 사이클.
9. ✅ HTTP 요청 = 첫 줄(메서드 URL 버전) + 헤더 + 빈줄 + 본문 구조.
10. ✅ 소켓으로 직접 HTTP 서버 만들기 — Spring이 이 역할을 대신해줌.

```
람다 / 메서드 참조

  Function   → apply()  (T → R)
  Supplier   → get()    (입력 없음)
  클래스::메서드 → 람다 축약형

어노테이션 + 리플렉션
  @interface 이름 { String attr() default ""; }  // 커스텀 어노테이션
  method.isAnnotationPresent(Ann.class)          // 어노테이션 있는지 확인
  method.invoke(target)                          // 리플렉션으로 메서드 실행

JUnit 5
  @Test, @BeforeAll(static), @BeforeEach, @DisplayName, @Disabled
  assertEquals(예상, 실제)
  assertThrows(예외.class, () -> { ... })

TDD
  Red(실패 테스트) → Green(최소 구현) → Refactor(정리)
```
