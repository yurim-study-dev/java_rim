### 1번 - ALTER TABLE로 컬럼 추가

```sql
ALTER TABLE post ADD COLUMN view_count INT NOT NULL DEFAULT 0;
```

> 기존 테이블에 새 컬럼을 추가할 때 `DEFAULT 0`을 지정하면 기존 행도 모두 0으로 채워진다.

### 8번 - LIMIT 페이징 (핵심!)

1페이지당 5개씩, 3페이지 조회 → 11~15번째 행

```sql
-- 방법 1: LIMIT 시작위치, 개수
SELECT id, title, view_count FROM post
ORDER BY view_count DESC
LIMIT 10, 5;

-- 방법 2: LIMIT 개수 OFFSET 시작위치 (동일한 결과)
SELECT id, title, view_count FROM post
ORDER BY view_count DESC
LIMIT 5 OFFSET 10;
```

**페이지 계산 공식**

```
시작위치 = (페이지번호 - 1) × 페이지당 개수
3페이지 = (3 - 1) × 5 = 10
```

| 페이지 | LIMIT 시작위치 | 개수 |
|--------|--------------|------|
| 1페이지 | LIMIT 0, 5 | 1~5번째 |
| 2페이지 | LIMIT 5, 5 | 6~10번째 |
| 3페이지 | LIMIT 10, 5 | 11~15번째 |

## 오전/오후: SQL 내장 함수 - 2.4

SQL은 조회 결과를 가공하거나 통계 데이터를 처리할 수 있도록 기본 내장 함수를 제공한다.

---

### 2.4.1 문자열 함수

#### CONCAT - 문자열 합치기

```sql
-- 이름과 이메일을 하나로 합쳐서 표현
SELECT name, email, CONCAT(name, ' (', email, ')') AS member_info
FROM member;
-- 결과: 하루 (haru@gmail.com)
```

#### LENGTH - 바이트 길이 반환

```sql
SELECT email, LENGTH('hello'), LENGTH('안녕하세요'), LENGTH(email) AS email_length
FROM member;
-- 영어: 1글자 = 1바이트, 한글: 1글자 = 3바이트
```

#### REPLACE - 문자열 치환

```sql
-- 본문에서 '안녕하세요'를 'HI'로 치환하여 조회
SELECT content, REPLACE(content, '안녕하세요', 'HI') AS replaced_content
FROM post
WHERE content LIKE '%안녕하세요%';
```

#### SUBSTRING - 문자열 자르기

```sql
-- 게시글 제목의 첫 10글자만 미리보기 (나머지는 ... 처리)
SELECT title, CONCAT(SUBSTRING(title, 1, 10), '...') AS preview
FROM post;
```

#### UPPER / LOWER - 대소문자 변환

```sql
SELECT email, LOWER(email) AS email_lower, UPPER(email) AS email_upper
FROM member;
```

#### TRIM - 앞뒤 공백 제거

```sql
SELECT email, TRIM(email) AS trimmed_email
FROM member;
```

### 2.4.2 날짜 함수

#### NOW() / CURDATE() - 현재 날짜·시간

```sql
SELECT NOW() AS current_datetime;   -- 2026-06-15 10:30:00 (날짜 + 시간)
SELECT CURDATE() AS curr_date;      -- 2026-06-15 (날짜만)
```

| 함수 | 반환값 | 용도 |
|------|--------|------|
| `NOW()` | 날짜 + 시간 | 정확한 현재 시각 비교 |
| `CURDATE()` | 날짜만 | 오늘 날짜 기준 필터링 |

#### DATE_FORMAT - 날짜 포맷 변환

```sql
-- 게시글 작성일을 한국식 형태로 포맷
SELECT id, title, DATE_FORMAT(created_at, '%Y년 %m월 %d일 %a %H시 %i분 %s초') AS write_date
FROM post;
```

**주요 포맷 코드**

| 코드 | 의미 | 예시 |
|------|------|------|
| `%Y` | 4자리 연도 | 2026 |
| `%m` | 2자리 월 | 06 |
| `%d` | 2자리 일 | 15 |
| `%H` | 24시간 형식 시 | 14 |
| `%i` | 분 | 30 |
| `%s` | 초 | 00 |
| `%a` | 요일 약어 | Sun |

#### DATE_SUB / DATE_ADD - 날짜 연산

```sql
-- 오늘 작성된 게시글 조회
SELECT id, title, created_at FROM post
WHERE created_at >= CURDATE();

-- 최근 7일 이내에 가입한 회원 조회
SELECT id, name, created_at FROM member
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY);

-- 가입한지 1개월이 지난 회원 조회
SELECT *, DATE_SUB(CURDATE(), INTERVAL 1 MONTH) AS before_1month
FROM member
WHERE created_at < DATE_SUB(CURDATE(), INTERVAL 1 MONTH);

-- 복합 단위: 34일 12시간 경과한 회원 조회
SELECT * FROM member
WHERE created_at < DATE_SUB(CURDATE(), INTERVAL '34 12' DAY_HOUR);
```

#### DATEDIFF - 날짜 차이 계산

```sql
-- 각 회원의 가입 후 경과 일수
SELECT name, created_at, DATEDIFF(CURDATE(), created_at) AS days_since_join
FROM member;
```

## 배운점

1. ✅ `ALTER TABLE ADD COLUMN`에 `DEFAULT` 값을 지정하면 기존 행에도 자동으로 채워진다.
2. ✅ 페이징 공식: `시작위치 = (페이지 - 1) × 페이지당 개수`. 시작위치는 0부터다.
3. ✅ `LIMIT 10, 5`와 `LIMIT 5 OFFSET 10`은 동일한 결과를 반환한다.
4. ✅ `LENGTH`는 바이트 기준이라 한글 1글자는 3바이트로 계산된다.
5. ✅ `SUBSTRING(문자열, 시작, 길이)` + `CONCAT`으로 미리보기 텍스트를 만들 수 있다.
6. ✅ `NOW()`는 날짜+시간, `CURDATE()`는 날짜만 반환 — 용도에 맞게 선택해야 한다.
7. ✅ `DATE_SUB(NOW(), INTERVAL 7 DAY)`로 n일 전 날짜를 계산해 기간 필터링이 가능하다.
8. ✅ `DATEDIFF(날짜1, 날짜2)`는 날짜1 - 날짜2의 일수 차이를 반환한다.

## 오늘 핵심 정리

```
페이징 공식
  시작위치 = (페이지 - 1) × 페이지당 개수
  LIMIT 시작위치, 개수  =  LIMIT 개수 OFFSET 시작위치

문자열 함수
  CONCAT(a, b)            → 문자열 합치기
  LENGTH(str)             → 바이트 길이 (한글 1자 = 3바이트)
  REPLACE(str, 대상, 대체) → 문자열 치환
  SUBSTRING(str, 시작, 길이) → 문자열 자르기
  UPPER / LOWER           → 대소문자 변환
  TRIM                    → 앞뒤 공백 제거

날짜 함수
  NOW()                             → 현재 날짜+시간
  CURDATE()                         → 현재 날짜만
  DATE_FORMAT(날짜, '%Y-%m-%d')      → 날짜 포맷 변환
  DATE_SUB(날짜, INTERVAL n 단위)    → n 전 날짜 계산
  DATE_ADD(날짜, INTERVAL n 단위)    → n 후 날짜 계산
  DATEDIFF(날짜1, 날짜2)             → 날짜 차이 (일수)
```
