## HTML 기본 구조 - 01

```html
<!DOCTYPE html>
<html lang="ko-KR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>페이지 제목</title>
  </head>
  <body>
    내용
  </body>
</html>
```

| 태그/속성 | 역할 |
|-----------|------|
| `<!DOCTYPE html>` | HTML5 문서임을 선언 |
| `<html lang="ko-KR">` | 문서 언어 설정 (스크린리더, SEO에 중요) |
| `<meta charset="UTF-8">` | 문자 인코딩 — 한글 깨짐 방지 |
| `<meta name="viewport">` | 모바일 화면 크기 대응 |
| `<title>` | 브라우저 탭에 표시되는 제목 |

## 시맨틱 마크업 - 00

**시맨틱(Semantic)** = "의미 있는" — HTML 태그가 구조와 의미를 함께 전달해야 함.

```html
<!-- 의미 있는 방식 (권장) -->
<h1>웹표준과 웹접근성</h1>
<p>구조를 나타내는 HTML, 스타일을 위한 CSS...</p>

<!-- 의미 없는 방식 (비권장) -->
<div style="font-size: 2em; font-weight: bold">웹표준과 웹접근성</div>
<div>구조를 나타내는 HTML, 스타일을 위한 CSS...</div>
```

> `<div>`는 시각적으로 같아 보여도 스크린리더, 검색엔진은 의미를 파악 못함.  
> `<h1>`은 "이게 제목이다"를 브라우저, 검색엔진, 스크린리더 모두에게 전달.

**웹접근성**: 나이, 성별, 장애 유무에 관계없이 모든 사람이 동등하게 사용할 수 있도록 설계.

## 제목과 단락 - 02

```html
<h1>카페W 매장 찾기</h1>       <!-- 가장 중요한 제목, 페이지당 1개 권장 -->
<p>카페 W를 가까이에서 경험해보세요.</p>   <!-- 단락(paragraph) -->
<p>고객님과 가장 가까이 있는 매장을 찾아보세요.</p>
```

- `h1` ~ `h6`: 제목 계층 구조. 숫자가 클수록 하위 제목.
- `p`: 하나의 문단. 블록 요소라 자동 줄바꿈.

## 이미지와 피규어 - 03

```html
<!-- 장식용 이미지: alt="" (빈 문자열) → 스크린리더가 무시 -->
<img src="../assets/images/tree.png" alt="" />

<!-- 의미 있는 이미지: alt에 설명 작성 -->
<img src="../assets/svg/chitchat.svg" alt="채팅 아이콘" width="50" height="50" />

<!-- figure: 이미지 + 설명을 묶는 그룹 태그 -->
<figure>
  <img src="../assets/svg/chitchat.svg" alt="" width="50" height="50" />
  <figcaption>채팅</figcaption>   <!-- 이미지 설명 캡션 -->
</figure>
```

| | alt="" | alt="설명" |
|--|--------|-----------|
| 장식 이미지 | ✅ 스크린리더 무시 | ❌ 불필요한 설명 읽힘 |
| 의미 있는 이미지 | ❌ 접근성 결여 | ✅ 내용 전달 |

## 하이퍼링크 - 04

```html
<!-- 절대 경로: 외부 URL -->
<a href="https://bootcamp.likelion.net/">멋쟁이 사자처럼 부트캠프</a>

<!-- 이미지 링크: a 태그 안에 img 삽입 -->
<a href="https://www.kurly.com/">
  <img src="../assets/cart/icon-cart.svg" alt="컬리 장바구니" />
</a>

<!-- 페이지 내 이동 (앵커): # + id -->
<p><a href="#top">맨 위로</a></p>
```

- `href`: 이동할 주소
- 이미지 링크: `<a>` 안에 `<img>` 넣으면 이미지 클릭 시 이동
- `#top`: 페이지 맨 위로 이동 (브라우저 기본 지원)

## 목록 - 05, 06

### 비순서 목록 `<ul>` (Unordered List)

```html
<ul>
  <li>카페 W 인기 강좌</li>
  <li>UI 구조 & 디자인</li>
  <li>React 프로그래밍</li>
</ul>
```

→ 순서가 없는 항목 나열. 기본적으로 ● 점으로 표시.

### 순서 목록 `<ol>` (Ordered List)

```html
<ol>
  <li>1단계</li>
  <li>2단계</li>
</ol>
```

→ 순서가 있는 항목. 기본적으로 1. 2. 3. 으로 표시.

### 정의형 목록 `<dl>` (Definition List) - 06

```html
<dl>
  <dt>Google Chrome</dt>   <!-- 용어(Definition Term) -->
  <dd>Google이 개발한 웹 브라우저로...</dd>   <!-- 설명(Definition Description) -->
  <dt>Mozilla Firefox</dt>
  <dd>Mozilla Foundation에서 개발한...</dd>
</dl>
```

→ 용어 + 설명 쌍으로 구성. 사전, 용어집, 자주 묻는 질문(FAQ) 등에 적합.

## 인라인 텍스트 요소(Phrasing Element) - 07

```html
<p><strong>무엇이 중요한지 알게된 시간!</strong></p>

<p>
  <em>시맨틱한 마크업</em>과 <em>접근성</em> 비중이 크게 다뤄져 좋았습니다.
</p>

<p>
  <span aria-hidden="true">★★★★★</span>      <!-- 스크린리더가 읽지 않음 -->
  <b><span aria-label="별점 5점">5점</span></b>  <!-- 대신 이걸 읽음 -->
  <i aria-label="교육생">우정민</i>
</p>
```

| 태그 | 시각적 | 의미 | 용도 |
|------|--------|------|------|
| `<strong>` | 굵게 | 중요함 | 핵심 강조 |
| `<em>` | 기울임 | 강조 | 어감 강조 |
| `<b>` | 굵게 | 없음 | 시각적 굵기만 |
| `<i>` | 기울임 | 없음 | 시각적 기울기만 |
| `<span>` | 없음 | 없음 | 인라인 묶음용 |

**웹접근성 속성:**
- `aria-hidden="true"`: 스크린리더가 해당 요소를 건너뜀
- `aria-label="설명"`: 스크린리더가 읽을 대체 텍스트 직접 지정

## 인용문과 줄바꿈 - 08

```html
<!-- 블록 인용문: 여러 줄, 들여쓰기 처리됨 -->
<blockquote>
  우리가 할 수 있는 노력은 과정이 전부야. <br />
  결과는 우리 손 안에 있는 게 아니야.
</blockquote>
드라마 <cite>미생</cite> 중에서

<!-- 인라인 인용문: 문장 안에서 짧게 인용 -->
<p>대사는 <q cite="https://...">우리가 할 수 있는 노력은 과정이 전부</q>야.</p>
```

| 태그 | 설명 |
|------|------|
| `<blockquote>` | 블록 단위 인용문 |
| `<q>` | 인라인 인용문 (따옴표 자동 추가) |
| `<cite>` | 출처 표시 (책, 영화, 드라마 제목 등) |
| `<br />` | 줄바꿈 (빈 태그, 자기 닫힘) |

## 테이블 - 09

```html
<table>
  <tr>                  <!-- 행(Row) -->
    <th>구분</th>        <!-- 헤더 셀 (굵게, 가운데 정렬) -->
    <th>HTML</th>
    <th>CSS</th>
    <th>Javascript</th>
  </tr>
  <tr>
    <td>&nbsp;</td>     <!-- 데이터 셀, &nbsp; = 공백 문자 -->
    <td>89</td>
    <td>92</td>
    <td>96</td>
  </tr>
</table>
```

| 태그 | 설명 |
|------|------|
| `<table>` | 테이블 전체 감싸는 태그 |
| `<tr>` | 행(Table Row) |
| `<th>` | 헤더 셀 — 굵게·가운데 정렬 자동 적용 |
| `<td>` | 일반 데이터 셀 |
| `&nbsp;` | Non-Breaking Space — 빈 칸을 채울 때 사용 |

## 배운점

1. ✅ 시맨틱 마크업 — `<div>`보다 의미 있는 태그(`h1`, `p`, `nav` 등)를 써야 검색엔진·스크린리더가 내용을 이해함.
2. ✅ `alt=""` vs `alt="설명"` — 장식 이미지는 빈 문자열, 의미 있는 이미지는 설명 작성.
3. ✅ `figure/figcaption` — 이미지와 캡션을 묶어 의미 단위로 그룹핑.
4. ✅ `ul/ol/dl` 세 가지 목록 — 비순서/순서/정의형 각각 용도가 다름.
5. ✅ `strong/em` vs `b/i` — 앞은 의미(시맨틱) + 스타일, 뒤는 스타일만.
6. ✅ `aria-hidden`, `aria-label` — 스크린리더 제어를 위한 접근성 속성.
7. ✅ `blockquote` vs `q` — 블록 인용 vs 인라인 인용, `cite`로 출처 표시.
8. ✅ `th` vs `td` — 헤더 셀과 데이터 셀 구분이 접근성과 의미 전달에 중요.

## 오늘 핵심 정리

```
HTML = 구조 + 의미
  시맨틱 태그를 써야 SEO, 접근성, 유지보수 모두 좋아짐
  div는 의미 없는 묶음용 — 남발 금지

HTML 기본 구조
  DOCTYPE → html[lang] → head(meta charset, viewport, title) → body

주요 태그 정리
  제목/단락  : h1~h6, p
  이미지     : img[alt], figure, figcaption
  링크       : a[href] — 절대경로, 이미지링크, 앵커(#id)
  목록       : ul/li (비순서), ol/li (순서), dl/dt/dd (정의형)
  인라인     : strong(중요), em(강조), b/i(스타일만), span(묶음)
  인용       : blockquote(블록), q(인라인), cite(출처), br(줄바꿈)
  테이블     : table > tr > th/td

웹접근성
  alt=""           → 장식 이미지 (스크린리더 무시)
  alt="설명"       → 의미 있는 이미지
  aria-hidden="true" → 스크린리더가 건너뜀
  aria-label="설명"  → 스크린리더가 읽을 대체 텍스트
```
