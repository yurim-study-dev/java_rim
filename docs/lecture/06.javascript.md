# 3 명령문과 주석
- 참고: https://ko.javascript.info/structure

## 3.1 명령문
- 자바스크립트는 명령문의 집합으로 구성되며 인터프리터가 명령문을 순차적으로 해석하여 실행
- 명령문은 줄바꿈이나 `;`(세미콜론)으로 구분

```js
console.log('Hello World!');
console.log('Hello ')
console.log('World!!');
console.log('Hello '); console.log('World!!!');
```

## 3.2 주석
- 주석은 코드의 실행에는 영향을 주지 않지만, 코드를 이해하기 쉽게 만들어주는 설명문
- 개발자가 코드의 목적이나 동작을 설명하거나, 임시로 코드를 비활성화할 때 사용

### 3.2.1 한 줄 주석
- `//` 로 지정하며 `//` 뒤의 모든 문자가 주석 처리됨

```js
// 주석입니다.
// console.log('Hello World!');
console.log('Hello '); // console.log('World!!!');
```

### 3.2.2 블럭 주석
- `/*` 로 시작하고 `*/`로 종료하며 시작과 종료 사이의 모든 문자가 주석 처리됨
- 여러줄에 걸쳐서 적용 가능

```js
/*
  console.log('Hello World!');
  console.log('Hello ');
*/

/* console.log('Hello '); */ console.log('World!!!');
```

# 4 변수
- 참고: https://ko.javascript.info/variables

## 4.1 변수 선언과 초기화
- 변수 선언은 변수를 사용하기 전에 미리 선언하는 것을 말하며, 초기화는 변수를 선언할 때 동시에 값을 할당하는 것을 의미

### 4.1.1 var
- `var 변수명;`: 전통적인 변수 선언
- `var 변수명 = 초기값;`: 변수 선언과 동시에 초기화

### 4.1.2 let
- `let 변수명;`: 블록 스코프 변수 선언
- `let 변수명 = 초기값;`: 블록 스코프 변수 선언과 동시에 초기화

### 4.1.3 const
- `const 변수명 = 초기값;`: 상수(constant, 재할당 불가) 선언과 동시에 초기화 (초기값 필수)

```js
let a;
let b, c;
const d=10, e=100;
```

# 6. 데이터 타입

## 6.1 강형 언어와 약형 언어

### 6.1.1 강형(strongly typed) 언어
- 변수 선언시 데이터 타입을 지정하는 언어(C, C++, Java 등의 언어)

- Java의 예
```java
String name = "하루";
name = 6; // 에러 발생!!!
```

### 6.1.2 약형(weakly typed) 언어
- 변수 선언시 데이터 타입을 지정하지 않는 언어(JavaScript, Python 등의 언어)
- 값에 따라서 자동으로 데이터 타입이 결정됨(동적 타입, dynamically typed)

- Javascript의 예
```js
let name = '하루';
name = 6; // 다른 타입으로 재할당 가능
```

## 6.2 원시 타입(Primitive type)
- 프로그래밍에서 더 이상 쪼갤 수 없는 가장 기본 단위의 데이터 타입을 의미
- 변수에 값을 직접 저장

### 6.2.1 number: 숫자
- 64비트 부동소수점 방식
- 정수, 실수, 음수, 양수 구별 없음

```js
let temp = 15;
let temp = 15.3;
```

### 6.2.2 string: 문자
- 큰 따옴표나 작은 따옴표 안에 기술
- 이스케이프 문자: 문자열 안에서 줄바꿈이나 탭 같은 제어 기능을 수행하거나, 따옴표와 같이 문자열의 시작과 끝을 나타내는 특수 문자를 직접 출력하기 위해 백슬래시(`\`) 뒤에 한 문자를 결합하여 사용하는 문자 조합
    - `\n`: 줄바꿈 (개행)
    - `\t`: 수평 탭
    - `\'`: 작은따옴표
    - `\"`: 큰따옴표
    - `\\`: 백슬래시 자체

```js
let haru = "하루";
let namu = '나무';
let haruSaid = "나무가 '월~월~' 이라고 말했다.";
let namuSaid = '하루가 "멍~멍~" 이라고 말했다.';
let brong = "브롱이가 \"부르부르\" 떨고 있다.";
let escapeMsg = "줄바꿈은 \n탭은 \t작은따옴표는 \'\n큰따옴표는 \"\n백슬래시는 \\";
```

### 6.2.3 boolean: 논리값
- 참(true) 또는 거짓(false) 둘 중 하나의 값을 가지는 데이터

```js
let isNew = true;
let isBest = false;
```

### 6.2.4 undefined: 값이 정의되지 않음
- 선언만 되고 값이 할당되지 않은 변수에는 타입과 값 모두 undefined로 지정됨

```js
let undefinedVar;
console.log(typeof undefinedVar, undefinedVar); // undefined undefined
```

### 6.2.5 null: 값이 없음을 명시적으로 지정
- 개발자가 명시적으로 값이 비어있음을 지정
- 타입은 object가 됨

```js
let nullVar = null;
console.log(typeof nullVar, nullVar); // object null
```

## 6.3 참조 타입(Reference type)
- 변수에 값을 직접 저장하지 않고 값을 참조하는 주소를 저장

- 종류
    - object
        - Array
        - Function
        - Date
        - RegExp
        - ...

# 7. 연산자
- 참고: https://ko.javascript.info/operators

## 7.1 산술 연산자
- `+`, `-`, `*`, `/`, `%`, `**`

```js
let age1 = 1 + 4; // 5
let age2 = 1 + 4 * 5; // 21
let age3 = (1 + 4) * 5; // 25
let age4 = 9 / 4 ; // 2.25
let age5 = 9 % 4; // 1 (%, 나머지 연산자)
let age6 = 2 ** 3; // 8 (** 거듭제곱 연산자)
let age7 = '나이는 ' + age1 + ' 입니다.'; // 나이는 5 입니다. (+, 결합 연산자)
```

- 💻 실습 (07-01 연산자): [ex07-01.html](../workspace/05_javascript/ex07-01.html)

## 7.2 대입 연산자
- 참고: https://ko.javascript.info/operators#ref-2477

- `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`
- 기본 대입 연산자(`=`): 우측 항목을 계산한 후 좌측 항목에 할당
- 덧셈 후 대입(`+=`): 좌측 항목에 우측 항목을 더한 후 좌측 항목에 할당(누적)
- 뺄셈 후 대입(`-=`)
- 곱셈 후 대입(`*=`)
- 나눗셈 후 대입(`/=`)
- 나머지 연산 후 대입(`%=`)
- 거듭제곱 후 대입(`**=`)

```js
let age = 20;
let year = 3 + 2; // year = 5
age = age + year; // age = 20 + 5 = 25
age += year; // age = age + year = 25 + 5 = 30
```

## 7.3 증감 연산자
- 참고: https://ko.javascript.info/operators#ref-2481

- `++`, `--`
- 값을 1 증가 또는 감소

```js
let count = 0;
count++; // 1
count++; // 2
count--; // 1
```

- 후위형(count++, count--)
    + 현재 값을 먼저 사용한 후 값을 증가 또는 감소
    + 다른 연산자와 함께 사용할 경우 원래 값이 연산에 반영된 후 값이 변경

- 전위형(++count, --count)
    + 값을 먼저 증가 또는 감소한 후 변경된 값을 사용
    + 다른 연산자와 함께 사용할 경우 증가/감소 값이 바로 반영

## 7.4 비교 연산자
- 참고: https://ko.javascript.info/comparison

- 두 항을 비교하여 참이면 true, 거짓이면 false를 반환
- `>`, `<`, `>=`, `<=`, `==`(동등), `===`(일치), `!=`, `!==`

```js
let result1 = 1 > 2; // false
let result2 = 10 <= 10; // true
let result3 = 100 == '100'; // true
let result4 = 100 === '100'; // false
let result5 = 100 != 100; // false
```

## 7.5 일치 연산자
- 참고: https://ko.javascript.info/comparison#ref-1417

- 일치 연산자(`===`, identical)
    + 두 데이터의 타입과 값을 모두 비교해서 값이 같아도 타입이 다르면 false

### 7.5.1 일치 연산자 비교 규칙
- 타입이 다르면 false를 반환하고 타입이 같을 경우는 다음 규칙을 따름
    + 숫자이고 같은 값이면 true
      ```js
      10 === 10 // true
      0 === 0 // true
      ```
    + 문자열일 경우 같은 위치에 같은 문자가 있고 대소문자까지 일치하면 true
      ```js
      'hello' === 'hello' // true
      'hello' === 'Hello' // false
      ```
    + boolean일 경우 모두 true이거나 모두 false이면 true
      ```js
      true === true // true
      false === false // true
      ```
    + 모두 null이거나 모두 undefined일 경우 true, null과 undefined는 false
      ```js
      null === null // true
      undefined === undefined // true
      null === undefined // false
      ```
    + 같은 객체를 참조할 경우 true, 속성이 모두 같은 객체라도 참조 주소가 다른 경우 false
      ```js
      [10, 20] === [10, 20] // false
      ```

## 7.6 동등 연산자
- 동등 연산자(`==`, equal)
    + 두 데이터의 타입이 다르면 적절히 형변환한 후 일치 연산(`===`)
    + 타입이 달라도 값이 같으면 true

### 7.6.1 동등 연산자 비교 규칙
- 타입이 같은 경우 두 값이 일치하다면(`===`) true
- 두 값의 타입이 다를 경우
    + null과 undefined는 true
      ```js
      null == undefined // true
      ```
    + 한 값이 숫자이고 다른 하나가 문자열이면, 문자열을 숫자로 변환한 후 비교
      ```js
      10 == '10' -> 10 === 10 // true
      ```
    + true는 1로 false는 0으로 변환한 후 비교
      ```js
      '1' == true -> 1 == true -> 1 === 1 // true
      ```

## 7.7 논리 연산자
- 참고: https://ko.javascript.info/logical-operators

- `||` (OR, 논리합)
    + Java 같은 언어에서는 둘 중 하나라도 참이면 참을 반환하는 연산자이지만 자바스크립트에서는 다음의 규칙을 따름
        * 앞의 값이 참이면 앞의 값 반환
        * 앞의 값이 거짓이면 뒤의 값 반환
      ```js
      let invalidId = (id.length < 4) || (id.length > 12); // id 길이가 4보다 작거나 12보다 클 경우 true, 4 ~ 12일 경우 false
      ```

- `&&` (AND, 논리곱)
    + Java 같은 언어에서는 둘 다 참이면 참을 반환하는 연산자이지만 자바스크립트에서는 다음의 규칙을 따름
        * 앞의 값이 참이면 뒤의 값 반환
        * 앞의 값이 거짓이면 앞의 값 반환
      ```js
      // length: 문자열의 글자수가 저장된 속성
      let validId = (id != null) && (id.length >= 4); // id 값이 null이나 undefined가 아니고 4글자 이상일 경우 true
      ```

- `!` (NOT, 부정)
    + 참이면 거짓, 거짓이면 참 반환
  ```js
  !(10 < 100) => !(true) // false
  ```

### 7.7.1 데이터 타입별로 truthy/falsy 값이 되는 기준
- falsy
    + boolean: false
    + number: 0, NaN(Not a Number)
    + string: ''
    + null
    + undefined
- truthy: falsy 이외의 값


## 7.8 삼항 연산자
- 참고: https://ko.javascript.info/ifelse#ref-2451

- 조건에 따라 값을 선택하는 연산자
- `조건 ? 참일 때의 값 : 거짓일 때의 값;`

```js
let num1 = 10;
let result1 = num1 % 2 === 0 ? '짝수' : '홀수';
console.log(result1); // '짝수'

let num2 = 15;
let result2 = num2 % 2 === 0 ? '짝수' : '홀수';
console.log(result2); // '홀수'
```

# 8. 조건문

## 8.1 if 문
- 참고: https://ko.javascript.info/ifelse

- 지정한 조건식이 참(truthy)일 경우 해당 구문 수행

```js
let num = 9;
if (num < 10) {
  console.log(num + '는 10보다 작습니다.');
}
```

## 8.2 if ~ else
- 지정한 조건식이 참일 경우와 거짓일 경우 각각 해당 구문 수행

```js
let num = 9;
if (num % 2 === 0) {
  console.log(num + '는 짝수입니다.');
} else {
  console.log(num + '는 홀수입니다.');
}
```

## 8.3 if ~ else if
- 지정한 조건식이 true일 경우 해당 구문을 수행하고 false일 경우 else if 문의 조건식을 순차적으로 비교하여 true에 해당하는 구문을 수행

```js
let age = 19;
if (age >= 30) {
  console.log('30대 이상입니다.');
} else if (age >= 20) {
  console.log('20대 입니다.');
} else if (age >= 10) {
  console.log('10대 입니다.');
} else {
  console.log('10살 미만입니다.');
}
```

## 8.4 switch
- 참고: https://ko.javascript.info/switch

- switch에 지정한 비교값과 매칭되는(`===`) case 구문 수행
- 일치하는 case가 없을 경우 default 구문 실행
- break 구문을 만날 때까지 또는 마지막 case나 default 구문까지 실행

```js
switch (비교값) {
  case 값1:
    수행구문1;
  case 값2:
    수행구문2;
    break;
  default :
    수행구문3;
}
```

# 9. 반복문
- 참고: https://ko.javascript.info/while-for

## 9.1 while 문
- 지정한 조건식이 참일 경우 조건이 거짓이 될 때까지 해당 블럭을 반복하여 수행

```js
let sum = 0;
let i = 1;
while (i <= 10) {
  sum += i;
  i++;
}
```

## 9.2 do...while 문
- 코드 블럭을 먼저 실행한 후 지정한 조건식이 참일 경우 조건이 거짓이 될 때까지 해당 블럭을 반복하여 수행
- 코드가 최소 한번은 실행되어야 할때 사용

```js
let sum = 0;
let i = 1;
do {
  sum += i;
  i++;
} while (i < 10);
```

## 9.3 for 문
- 지정한 횟수만큼 반복적인 작업을 할 경우 사용

```js
let sum = 0;
for (let i=1; i<=10; i++) {
  sum += i;
}
```

## 9.4 break
- 반복문이나 switch문을 즉시 종료
- break를 감싸고 있는 반복문이나 switch문의 코드 블럭(`{}`)을 빠져나옴

```js
for (let i=1; true; i++) {
  sum += i;
  if (i === 10) {
    break;
  }
}
```

## 9.5 continue
- 반복문 내에서 남아있는 코드를 건너뛰고 다음 반복으로 실행이 넘어감

```js
for (let i=1; i<=10; i++) {
  if (i % 2 === 0) {
    continue;
  }
  sum += i;
}
```

# 10. 참조 타입(Object, 객체)
- 참고: https://ko.javascript.info/object

## 10.1 object란?
- key-value 쌍의 데이터 집합(속성, property)
- 속성의 값으로 모든 데이터 타입 지정 가능
    + 속성의 값으로 함수가 지정된 경우 메서드(method)라 부름
- 하나의 객체는 여러개의 속성과 메서드를 포함할 수 있음
- 객체의 속성과 메서드에 접근할 때는 dot 표기법( . )을 사용하거나 대괄호 표기법( ['속성명'] )을 사용

```js
// 네개의 변수 정의
let kor = 100;
let eng = 80;
let math = 90;
const sum = kor + eng + math;

console.log('총점', sum); // 총점 270

eng += 10;
sum = kor + eng + math;
console.log('수정된 총점', sum); // 수정된 총점 280
```

```js
// 하나의 객체 정의
let score = new Object();
score.kor = 100;
score.eng = 80;
score['math'] = 90;
score.sum = score['kor'] + score.eng + score.math;

console.log('총점', score.sum); // 총점 270

score.eng += 10;
score.sum = score.kor + score.eng + score.math;
console.log('수정된 총점', score.sum); // 수정된 총점 280
```

## 10.2 객체 생성 방법 - Object 생성자 함수
- Object 생성자 함수로 빈 객체를 생성한 후 속성과 메서드를 추가

```js

user['married'] = false;

console.log(user['name'], user.age, user.job, user['married']); // haru 6 sleep false
console.log(typeof user, user); // object { name: 'haru', age: 6, job: 'sleep', married: false }
```

# 12. 함수
- 참고: https://ko.javascript.info/function-basics

## 12.1 함수란?
- 함수(Function)는 특정 작업을 수행하는 코드 블록을 하나의 단위로 묶은 것
- 여러 명령어를 하나의 단위로 묶어서 재사용 가능하게 만듦
- 코드의 중복을 줄이고 가독성을 높이며 유지보수를 쉽게 함
- 함수명, 매개변수 목록, 실행구문, 반환값으로 구성됨

### 12.1.1 함수 정의
```js
function 함수명(매개변수1, 매개변수2, ...) {
  실행할 구문1;
  실행할 구문2;
  return 반환값;
}
```

### 12.1.2 함수 사용
```js
let result = 함수명(인자1, 인자2);
```

## 12.2 함수 생성

### 12.2.1 함수 선언문 (Function Declaration)
- function 키워드로 시작하는 함수 정의
```js
function add(x, y){
  const result = x + y;
  return result;
}
add(10, 20);
```

### 12.2.2 함수 표현식 (Function Expression)
- 함수 정의를 변수에 할당하여 변수명을 함수명처럼 사용
```js
const add = function(x, y){
  const result = x + y;
  return result;
};
add(10, 20);
```

### 12.2.3 화살표 함수 (Arrow Function)
- 참고: https://ko.javascript.info/arrow-functions-basics

- 함수 표현식의 대안으로 간결하게 함수 정의
- 실행할 코드가 하나만 있다면 함수 본문의 중괄호 생략 가능
- 함수 본문의 중괄호가 생략될 경우 함수의 코드가 자동으로 리턴값으로 사용됨
- 매개 변수가 하나만 있다면 매개변수를 감싸는 괄호 생략 가능

```js
// 기존 함수(표현식)
const add = function(x, y) {
  return x + y;
};

// 화살표 함수
const add = (x, y) => {
  return x + y;
}

// 화살표 함수 축약
const add = (x, y) => x + y;
```

```js
// 기존 함수(표현식)
const add10 = function(x) {
  return x + 10;
};

// 화살표 함수
const add10 = (x) => {
  return x + 10;
}

// 화살표 함수 축약
const add10 = x => x + 10;
```

# 13. 이벤트와 브라우저 제어

## 13.1 이벤트란?
- 브라우저에서 어떤 일이 일어났음을 알려주는 신호
- 클릭(click), 키보드 입력(keydown/keyup), 폼 전송(submit) 등이 포함됨

## 13.2 이벤트 처리
- 브라우저는 HTML 요소에 이벤트가 발생했을 때 지정한 자바스크립트 함수(이벤트 핸들러)를 실행할 수 있는 방법을 제공

### 13.2.1 HTML 속성을 이용한 이벤트 연결 (인라인 방식)
- HTML 태그의 이벤트 속성(예: `onclick`, `onsubmit` 등)에 실행할 함수명을 직접 지정하여 연결

```html
<!-- 버튼 클릭 시 checkId 함수 실행 -->
<button type="button" onclick="checkId()">중복 체크</button>
```

```js
function checkId() {
  console.log('아이디 중복 체크 시작');
}
```

### 13.2.2 폼 전송(submit) 이벤트 연결 예시
- form 태그의 `onsubmit` 속성에 실행할 함수를 지정

```html
<!-- 폼 전송 시 startLogin 함수 실행 -->
<form onsubmit="join()">
  <button type="submit">회원 가입</button>
</form>
```

```js
function join() {
  console.log('폼 전송 시작됨');
}
```

## 13.3 Event 객체와 브라우저 기본 동작 제어
- Event 객체: 이벤트가 발생했을 때 이벤트 종류, 발생 대상 요소 등 상세 정보를 담고 있는 객체
- Event 객체 획득: HTML 이벤트 속성에서 함수를 호출할 때 인자로 `event` 키워드를 직접 기재하여 넘겨주고, 자바스크립트 함수 선언 시 매개변수로 받아서 사용

```html
<!-- HTML에서 event 객체를 명시하여 함수로 전달 -->
<form onsubmit="join(event)">
  <button type="submit">회원 가입</button>
</form>
```

```js
function join(e) {
  // 브라우저의 기본 동작(form의 submit 자동 전송 및 새로고침)을 취소
  e.preventDefault();
  console.log('기본 전송 동작이 취소되고 입력값을 검증하는 커스텀 코드 실행');
}
```

## 13.4 브라우저 알림 및 확인 창 제어
- `alert(msg)`: 단순 알림 및 경고 창 출력
- `confirm(msg)`: 확인 및 취소 버튼이 있는 대화상자 출력
    + 반환값(리턴값): 사용자가 확인 버튼을 누르면 `true` 반환, 취소 버튼을 누르거나 창을 닫으면 `false` 반환

```js
const isConfirmed = confirm('정말로 삭제하시겠습니까?');
if (isConfirmed) {
  console.log('삭제 진행');
} else {
  console.log('삭제 취소');
}
```

- DOM(Document Object Model) 이란?
    + 브라우저가 HTML 문서를 객체의 트리 구조로 표현한 모델(부모-자식 관계로 연결된 계층 구조)
    + 브라우저는 웹서버에서 다운로드 받은 텍스트 기반의 HTML 문서를 파싱하면서 HTML 문서의 각 구성 요소를 트리구조의 객체로 만들어 자바스크립트로 제공함
    + 노드(Node): DOM 트리구조의 모든 구성원은 각각의 객체로 인식되며 이러한 객체 하나하나를 노드라고 함
    + DOM API를 이용하면 정적인 HTML 문서를 자바스크립트로 동적 제어 가능(특정 요소 탐색 및 속성 제어 등)

## 14.1 Document 객체
- 브라우저의 최상위 객체는 window, 웹페이지의 최상위 객체는 window.document
- HTML 문서 전체를 나타냄
- 모든 DOM 조작의 시작점

## 14.2 주요 노드
- DOM에는 여러 종류의 노드가 존재하며 대표적인 노드는 다음과 같음
    + 문서노드(document node): 문서 전체
    + 요소노드(element node): HTML 태그
    + 속성노드(attribute node): 태그의 속성
    + 텍스트노드(text node): 태그 내의 텍스트 내용

## 14.3 노드 찾기
- 참고: https://ko.javascript.info/searching-elements-dom

### 14.3.1 CSS 선택자(Selector) 이용
- Selector: CSS에서 사용하는 노드 선택 구문
    + 참고: https://developer.mozilla.org/ko/docs/Web/CSS/CSS_selectors
- `document.querySelector(selector)`: 지정한 selector 구문에 매칭되는 노드 중 첫 번째 노드를 반환함
- `document.querySelectorAll(selector)`: 지정한 selector 구문에 매칭되는 노드 목록을 반환함(length 속성과 인덱스를 이용한 요소 접근이 가능한 배열과 유사한 객체)

```html
<input type="text" id="title" class="list-item" placeholder="제목">
<input type="text" class="list-item" placeholder="내용">
```

```js
// 태그명으로 찾기 (첫 번째 input 요소 반환)
const inputElem = document.querySelector('input');

// id 속성값으로 찾기 (id가 title인 요소 반환)
const titleElem = document.querySelector('#title');

// class 속성값으로 찾기 (class가 list-item인 모든 요소를 유사 배열로 반환)
const items = document.querySelectorAll('.list-item');
```

## 14.4 폼 요소의 값 제어
- DOM 객체의 속성으로 저장되어 바로 읽고 쓸 수 있음
- 폼 입력 값 검증 시 각 폼 요소(input, textarea, select, checkbox, radio 등)의 속성을 조회하여 처리함

### 14.4.1 텍스트 입력 요소 (input, textarea)
- `value` 속성을 이용하여 텍스트 값을 조회 및 설정함

```js
const inputElem = document.querySelector('input');
console.log(inputElem.value); // 입력된 값 조회
inputElem.value = 'newValue'; // 값 설정
```

### 14.4.2 선택 상자 (select)
- `value` 속성을 이용하여 선택된 option의 값을 조회 및 설정함

```js
const selectElem = document.querySelector('select');
console.log(selectElem.value); // 선택된 옵션의 값 조회
selectElem.value = 'optionValue'; // 특정 옵션으로 선택 변경
```

### 14.4.3 체크박스 (checkbox)
- `checked` 속성을 이용하여 체크 여부(true 또는 false)를 조회 및 설정함

```js
const checkboxElem = document.querySelector('input[type="checkbox"]');
console.log(checkboxElem.checked); // 체크 여부 확인 (true/false)
checkboxElem.checked = true; // 체크 설정
```

### 14.4.4 라디오 버튼 (radio)
- 그룹으로 묶인 라디오 버튼 중에서 현재 선택된(checked) 버튼 요소를 `:checked` 선택자로 찾아 `value` 속성을 조회
- 특정 값을 가진 라디오 버튼을 선택 상태로 변경하려면 해당 요소의 `checked` 속성을 `true`로 설정

```js
// name 속성이 "gender"인 라디오 버튼 중 선택된 요소 찾기
const checkedRadio = document.querySelector('input[name="gender"]:checked');
if (checkedRadio) {
  console.log(checkedRadio.value); // 선택된 라디오의 값 조회
}

// 특정 값을 가진 라디오 버튼 선택 변경 (예: "female" 값을 가진 버튼을 선택)
document.querySelector('input[name="gender"][value="female"]').checked = true;
```

## 14.5 DOM 객체를 이용한 이벤트 등록 (권장)
- HTML 태그에 직접 이벤트 속성을 지정하는 대신, 자바스크립트에서 요소를 탐색하여 이벤트를 등록하는 방식
- 관심사 분리(HTML 마크업과 자바스크립트 로직 분리) 및 유지보수성을 극대화하기 위해 실무에서 권장하는 방식

### 14.5.1 addEventListener 등록 방식
- `querySelector`로 대상을 가져온 뒤 `addEventListener`를 통해 이벤트를 바인딩함
- 이벤트 객체는 핸들러 함수의 첫 번째 매개변수로 브라우저가 자동 전달함

```html
<form id="joinForm" action="/" method="POST">
  <button type="button" id="checkIdBtn">중복 체크</button>
  <button type="submit">회원 가입</button>
</form>
```

```js
// 1. 단순 클릭 이벤트 등록
const chkIdBtn = document.querySelector('#checkIdBtn');
chkIdBtn.addEventListener('click', function() {
  console.log('아이디 중복 체크 시작');
});

// 2. 폼 전송(submit) 이벤트 등록 및 기본 동작 제어
const joinForm = document.querySelector('#joinForm');
joinForm.addEventListener('submit', function(event) {
  // 브라우저의 기본 동작(form의 submit 자동 전송 및 새로고침)을 취소
  event.preventDefault();
  console.log('기본 전송 동작이 취소되고 입력값을 검증하는 커스텀 코드 실행');
});
```
